## Le modpack du serveur

Télécharge le ZIP qui contient tous les mods du serveur, et garde-le tel quel. Ne l’ouvre pas et ne le décompresse pas : CurseForge va s’occuper de tout.


Télécharger le modpack










## Vérifie que tu possèdes Minecraft Java


Le serveur fonctionne avec **Minecraft: Java Edition sur ordinateur** . Les versions Bedrock pour téléphone, console et Windows ne peuvent pas rejoindre ce serveur.


Télécharger le launcher officiel











## Installe l’application CurseForge


Télécharge CurseForge depuis son site officiel. Sur Windows, la version **Standalone** suffit : Overwolf n’est pas obligatoire.


Au premier démarrage, choisis **Minecraft** , puis l’installation standard recommandée.


Télécharger CurseForge











## Importer le modpack dans CurseForge


Dans CurseForge, ouvre la section Minecraft et clique sur **Importer** ou **Import** . Choisis ensuite le fichier **ModPack Regalade v1.3.zip** . Tu peux aussi cliquer-glisser le ZIP dans CurseForge.


CurseForgeMinecraftImporterChoisir le ZIP











## Laisse CurseForge terminer l’installation


Le profil **** apparaît dans « Mes modpacks ». CurseForge télécharge tous les mods et leurs dépendances : c’est magique oOo.


Attends que l’activité soit terminée avant de cliquer sur **Jouer** .











## Alloue suffisamment de mémoire RAM


Dans les paramètres Minecraft de CurseForge, règle la mémoire allouée à **8 192 Mo** si ton ordinateur possède au moins 16 Go de RAM. Avec 8 Go de RAM au total, commence à 6 144 Mo et ferme les autres programmes.


N’alloue pas toute la mémoire de l’ordinateur à Minecraft : Windows doit aussi pouvoir fonctionner.











## Lance le jeu ! (letzgo !)


Dans CurseForge, ouvre **** puis clique sur **Jouer** . Connecte-toi au launcher Minecraft avec le compte Microsoft qui possède Java Edition.


Le premier démarrage est le plus long. Une fenêtre qui semble immobile pendant quelques minutes n’est pas forcément bloquée.











## Tu vois le menu principal ? C’est installé.









## Installer une mise à jour




- Télécharge le nouveau ZIP indiqué sur cette page.

- Importe-le comme un nouveau profil CurseForge.

- Lance-le une fois et vérifie qu’il fonctionne.

- Supprime l’ancien profil seulement après vérification.









CurseForge affiche « fichier invalide »
Vérifie que tu as choisi le ZIP complet du modpack sans le décompresser. Un dossier ou un ZIP recréé manuellement ne peut pas être importé.

Le jeu ferme avec une erreur de mémoire
Vérifie la mémoire allouée dans CurseForge. Essaie 8 192 Mo sur une machine de 16 Go ou plus, puis ferme les applications lourdes avant de relancer.

Le serveur annonce des mods incompatibles
Tu utilises probablement un ancien profil ou un profil modifié. Réimporte la dernière archive indiquée en haut de cette page sans ajouter ni mettre à jour de mod.
