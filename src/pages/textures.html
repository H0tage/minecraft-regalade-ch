Changer le look du jeu

Packs de textures

Ces packs sont entièrement facultatifs. Ils s’installent sur ton ordinateur et ne changent rien pour les autres joueurs. Voici cinq directions visuelles, du Minecraft presque intact au dessin animé complet.

À garder en tête

Un pack retravaille surtout les blocs de Minecraft. Les machines Create, les poissons, les Stargates et les autres contenus ajoutés par les mods conserveront souvent leurs textures d’origine. Les packs en 16x restent donc les plus homogènes avec Régalade.

Installation

Ajouter un pack à ton profil Régalade

  1. Télécharge le fichier du pack depuis son site officiel.
  2. Dans Minecraft, ouvre Options → Packs de ressources → Ouvrir le dossier.
  3. Place le fichier ZIP dans ce dossier sans le décompresser.
  4. Active le pack dans la colonne de droite, puis clique sur Terminé.
