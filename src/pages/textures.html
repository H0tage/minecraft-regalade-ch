Installation

Activer un shader dans le profil Régalade

  1. Dans Minecraft, ouvre Options → Options vidéo → Packs de shaders.
  2. Sélectionne Complementary Reimagined, déjà fourni avec le modpack.
  3. Pour ajouter un autre shader, ouvre le dossier depuis ce menu et dépose son fichier ZIP dedans.
  4. Choisis le shader dans la liste, puis ajuste son profil selon tes performances.

Installation

Ajouter un pack à ton profil Régalade

  1. Télécharge le fichier du pack depuis son site officiel.
  2. Dans Minecraft, ouvre Options → Packs de ressources → Ouvrir le dossier.
  3. Place le fichier ZIP dans ce dossier sans le décompresser.
  4. Active le pack dans la colonne de droite, puis clique sur Terminé.
