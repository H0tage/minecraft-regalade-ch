Les filtres @ du modpack

Un filtre comme @create limite le catalogue aux objets de Create. Tu peux ensuite ajouter un mot, comme @create train ou @chipped verre, pour préciser la recherche.

Quel code taper dans JEI ?

Ce tableau rassemble les mods qui ajoutent des objets ou des blocs consultables dans JEI. Les bibliothèques, les optimisations et les modifications purement visuelles sont volontairement laissées de côté.

Retrouve le mod dans cette page

Tape son code dans Minecraft

Recopie le filtre dans la barre de recherche située sous le catalogue JEI.

Aucun mod ne correspond à cette recherche. Essaie avec un nom plus court.
