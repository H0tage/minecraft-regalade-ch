Scanner, médailles et collection avancée

Savoir exactement ce qu’il te manque

Quand les Binders commencent à se remplir, le Buddysteel Scanner prend le relais. Il mémorise les cartes que tu lui montres, affiche les trous dans chaque série et permet au Buddysteel Charger de vérifier les objectifs de collection avancés.

01

Le catalogue personnel

Fabriquer le Buddysteel Scanner

Buddysteel Ingot Buddysteel IngotQuartzBuddysteel Ingot Buddysteel Ingot

Ce qu’il enregistre

Le Scanner de base suit les numéros déjà trouvés. Des Scanner Chips permettent ensuite de distinguer les versions foil, les grades ou toutes les variantes.

02

Mettre le catalogue à jour

Scanner les cartes et les Binders

Scanner un Binder

Place le Binder dans la seconde main, garde le Scanner dans la main principale et fais un clic droit.

Scanner l’inventaire

Accroupis-toi puis fais un clic droit avec le Scanner pour lire les objets de collection transportés.

Scanner un présentoir

Fais un clic droit sur un bloc qui contient des cartes, comme un Display ou un Card Stand.

Ouvre ensuite le Scanner avec un clic droit pour consulter les collections enregistrées. Pense à le rescanner après une grosse séance d’ouverture ou d’échange.

03

Plusieurs niveaux de complétion

Passer des numéros aux variantes

0

Collection normale

Posséder chaque numéro du set au moins une fois.

1

Collection foil

Enregistrer une variante brillante de chaque carte.

2

Collection gradée

Enregistrer une version gradée de chaque carte.

3

Foil et gradée

Réunir les deux propriétés sur chaque numéro.

4

Toutes les variantes

Suivre chaque finition et chaque grade disponible.

Les Luminis Scanner Chips ajoutent le suivi des foils. Les Zylex Scanner Chips ajoutent le suivi des grades. Le Perfect Scanner Chip ouvre le suivi complet.

04

Valider une série complète

Utiliser le Buddysteel Charger

Le Charger lit la progression enregistrée dans le Scanner. Une fois un set complété au niveau demandé, il peut transformer une Blank Buddysteel Medal en médaille de cette collection, puis améliorer cette médaille avec les matériaux avancés du mod.
