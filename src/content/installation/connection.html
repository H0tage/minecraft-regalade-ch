Première partie

Lancer le bon Minecraft depuis CurseForge

Ouvre CurseForge

Lance l’application CurseForge sur ton ordinateur. Si elle te demande de choisir un jeu, clique sur Minecraft.

Ne lance pas directement Minecraft depuis un raccourci classique : il faut passer par CurseForge pour charger tous les mods du serveur.

Ouvre « Mes modpacks »

Dans la partie Minecraft de CurseForge, ouvre l’onglet Mes modpacks ou My Modpacks. Tu dois voir une vignette nommée Régalade Minecraft.

Tu ne vois pas ce profil ? Retourne dans l’onglet « Guide d’installation » de cette page et importe d’abord le modpack.

Lance le profil Régalade

Clique sur la vignette Régalade Minecraft, puis sur le bouton Jouer.

Le launcher officiel de Minecraft va s’ouvrir. S’il te demande de te connecter, utilise le compte Microsoft qui possède Minecraft: Java Edition.

Deuxième partie

Ajouter Régalade à la liste des serveurs

Ouvre le menu Multijoueur

Depuis le menu principal de Minecraft, clique sur Multijoueur ou Multiplayer.

Si Minecraft affiche un avertissement concernant le jeu en ligne, lis-le puis clique sur le bouton permettant de continuer.

Clique sur « Ajouter un serveur »

En bas de l’écran multijoueur, clique sur Ajouter un serveur ou Add Server.

N’utilise pas « Connexion directe » : ajouter le serveur permet de conserver son adresse pour les prochaines fois.

Remplis les deux champs

Dans Nom du serveur, écris Régalade. Ce nom sert uniquement à reconnaître le serveur dans ta propre liste.

Dans le champ Adresse du serveur, colle l’adresse complète ci-dessous.

89.217.231.153:25565

Laisse le réglage des packs de ressources sur sa valeur par défaut, puis clique sur Terminé ou Done.

Sélectionne le serveur Régalade

Tu reviens maintenant à la liste des serveurs. Une nouvelle ligne nommée Régalade doit apparaître.

Clique une fois sur cette ligne, puis clique sur Rejoindre le serveur. Tu peux aussi double-cliquer directement sur la ligne.

Patiente pendant la première connexion

Minecraft contacte le serveur, vérifie les mods puis charge le monde. La première connexion peut être plus longue que les suivantes.

Quand le terrain apparaît et que tu peux déplacer ton personnage, c’est bon : tu es sur Régalade.

Pour revenir les prochaines fois

Ouvre CurseForge, lance Régalade Minecraft, clique sur Multijoueur, puis double-clique sur Régalade. L’adresse restera enregistrée.

Si la connexion ne fonctionne pas

Le serveur affiche une croix rouge ou reste introuvable

Vérifie que l’adresse a été recopiée sans espace ni faute. Si elle est correcte, le serveur est peut-être momentanément éteint ou en maintenance.

Minecraft parle de mods incompatibles ou manquants

Tu n’utilises probablement pas la bonne version du modpack. Ferme le jeu, retourne dans CurseForge et vérifie que tu as lancé le profil Régalade le plus récent sans modifier ses mods.

La connexion expire ou affiche « timed out »

Vérifie ta connexion Internet, ferme complètement Minecraft puis relance le profil depuis CurseForge. Si le problème touche plusieurs joueurs, il vient probablement du serveur.

Le serveur refuse ton pseudo ou demande une autorisation

Vérifie que tu es connecté au bon compte Microsoft. Si le serveur utilise une liste d’autorisation, demande à un administrateur de vérifier ton pseudo Minecraft exact.
