Voir le paysage au loin dès ta première connexion

Cette carte facultative permet à ton jeu d’afficher les montagnes, les vallées et les constructions déjà enregistrées, même si tu n’y as jamais mis les pieds. Installe d’abord le modpack Régalade dans CurseForge.

Télécharger la carte (.zip)

Télécharge la carte sur SwissTransfer

Le bouton ci-dessus ouvre SwissTransfer. Clique sur Télécharger et attends la fin du téléchargement de voxy.zip. Tu le retrouveras normalement dans Téléchargements.

Le ZIP pèse environ 10 Go. Il faut encore 10 Go libres dans le profil pour l’extraire. Si tout est sur le même disque, prévois un peu plus de 20 Go avant de commencer.

Ouvre le dossier du profil Régalade

Ferme Minecraft. Dans CurseForge, choisis Minecraft, puis Mes modpacks. Clique sur la vignette du profil Régalade avec lequel tu joues. Ouvre son menu ⋯ et choisis Ouvrir le dossier (Open Folder en anglais).

Dans la fenêtre qui s’ouvre, tu dois voir les dossiers mods et config côte à côte. C’est ce qu’on appelle la racine du profil. Garde cette fenêtre ouverte.

Tu as déjà un dossier .voxy dans ce profil ?

Ouvre .voxy, puis saves. Compare son contenu avec le dossier .voxy/saves du ZIP. Si un dossier porte exactement le même nom aux deux endroits, ajoute -ancien à son nom dans ton profil pour garder tes paysages précédents. Reviens ensuite au niveau de mods et config.

Extrais le ZIP dans ce dossier

Sur Windows, dans la fenêtre du profil, appuie sur Alt + D pour sélectionner l’adresse du dossier, puis sur Ctrl + C pour la copier. Dans Téléchargements, fais un clic droit sur voxy.zip et choisis Extraire tout….

Clique dans le champ de destination, appuie sur Ctrl + A pour sélectionner le chemin proposé, puis sur Ctrl + V pour le remplacer par celui du profil. Clique sur Extraire et attends la fin de la copie.

Sur Mac, double-clique sur le ZIP dans le Finder. Appuie sur ⌘ + Maj + . pour afficher les dossiers cachés. Ouvre le dossier extrait si nécessaire, puis copie le dossier .voxy à côté de mods et config. Si le Finder te propose de fusionner avec un dossier existant, choisis Fusionner.

Vérifie que les trois dossiers sont côte à côte

Retourne dans la fenêtre du profil. Voici ce que tu dois y retrouver, parmi tes autres dossiers.

Profil Régalade/
├── .voxy/
├── config/
└── mods/

Ouvre .voxy. Tu dois y voir saves. Si tu as un dossier voxy qui contient lui-même .voxy, déplace le dossier avec le point à côté de mods.

Tu peux maintenant lancer ton profil dans CurseForge et rejoindre le serveur.

L’IP du serveur a changé et je ne vois plus les paysages au loin

Dans .voxy/saves, le nom du dossier de la carte doit correspondre à l’adresse IP que tu utilises dans Minecraft. Si tu saisis aussi le port, Voxy remplace les deux-points par un tiret bas. Par exemple, l’adresse 192.0.2.10:25565 donne le dossier 192.0.2.10_25565.

Si l’IP change, connecte-toi une fois avec la nouvelle adresse, puis ferme Minecraft. Dans ton profil, ouvre .voxy, puis saves. Copie le nom exact du dossier que Voxy vient de créer pour la nouvelle IP, puis ajoute -sauvegarde au nom de ce nouveau dossier pour le garder de côté. Renomme le dossier de l’ancienne IP en y collant le nom copié. Relance le jeu et rejoins le serveur.
